to do something and sometimes me today and me yesterday are two different
persons.

Some things about this repo:

- Commit messages are made by chezmoi, so they might not be helpful

- I want things to only affect environment that is intended for them, so a lot
  of things are configured to work differently between my main terminal, kitty,
  and other terminals.

- I really like black-with-yellowish-highlights color scheme `:bee:`

If you see some obvious mistake in scripts or configs, you can open PR, I might
even be able to merge it (if I figure out how GitHub works)
